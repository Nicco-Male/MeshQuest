# Languages / Lingue

English is the source language for technical documentation. The Italian guide is maintained alongside the main README. Contributions for additional languages are welcome.

Proposed future layout:

```text
README.md                 # English entry point + prominent language navigation
docs/README.it.md         # Italian guide
docs/README.<lang>.md     # Optional additional translated guides
```

Please keep security warnings, non-implemented functionality, technical restrictions and version numbers consistent across translations. Avoid claiming that untested radio features are implemented.
