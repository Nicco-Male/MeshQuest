# Contributing to MeshQuest

Thanks for contributing. Before opening a pull request, run `pytest -q` and update the English documentation first, followed by the Italian guide for user-facing changes.

Please avoid introducing unverified claims about Meshtastic packet routing. Radio-sensitive changes should cite the relevant protocol or firmware version and include synthetic fixture tests. Do not commit credentials, real gateway tokens or private location data.

Use English for code identifiers and pull request descriptions; both English and Italian are welcome for discussion. The project is in alpha; API backwards compatibility is not guaranteed.
